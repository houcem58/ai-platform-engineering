# Contributing

This repository documents the engineering management playbook for the AI & Data Platform team. Contributions that improve the methodology, add missing artefacts, or correct inaccuracies are welcome.

## What to contribute

- Corrections to standards, governance frameworks, or process documentation
- Additional artefact templates (model card variants, ADR templates for specific domains, etc.)
- Improvements to the onboarding guide based on real onboarding feedback
- Extensions to the release management or MLOps standards documentation

## How to contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b docs/your-change`
3. Make your changes — keep documentation grounded in real engineering practice
4. Submit a pull request with a clear description of what changed and why

## Standards

- Documentation must reflect sound engineering management practice
- ADRs follow the template in `docs/07-engineering-standards.md`
- File naming convention: `NN-descriptive-name.md`
- Do not add speculative or aspirational content — document what is real
